Q1: Investigating a Compromised System – Directory Analysis
Directories analyzed: /bin, /etc, /var, /usr, /tmp, /opt, /boot, /home
- /etc: Contains system configuration files. Attackers may modify passwd, shadow, or network configs.
- /bin: Stores essential binaries. Replacing commands like ls or ps can hide attacker activity.
- /var: Holds logs and variable data. Intrusion evidence may be found in /var/log/auth.log, etc.
- /usr: Contains user-installed software and libraries. Targeted for persistence.
- /tmp: Used for staging payloads due to write permissions.
- /opt: Optional software. Vulnerable if misconfigured.
- /boot: Kernel and bootloader files. Rarely targeted.
- /home: User directories. Attackers may drop tools or hide data.
